# Real-World Readiness Checklist

The case study is educational. Before using the architecture with real money or real investment recommendations:

- [ ] Replace synthetic data with verified adjusted-price data.
- [ ] Record source, extraction timestamp and data version.
- [ ] Verify dividends, splits, corporate actions and trading calendars.
- [ ] Add transaction costs, taxes, slippage and liquidity constraints.
- [ ] Add sector, single-name and turnover constraints.
- [ ] Use robust expected-return estimates rather than raw historical means alone.
- [ ] Add out-of-sample / walk-forward validation.
- [ ] Add benchmark and portfolio rebalancing rules.
- [ ] Model non-normal tails and regime changes for stress analysis.
- [ ] Add unit tests and regression tests for key metrics.
- [ ] Review governance, suitability and regulatory requirements before deployment.
